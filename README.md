I like software that quietly takes a chore off someone's plate, like turning a pile of catering receipts into a prep sheet so nobody has to type it up by hand. The rest of the time I'm pulling apart sports data: who passes to whom, which set pieces actually work, why upsets happen.

### Things I've built

- 🍽️ **[catering-execution-generator](https://github.com/bjrodrigu/catering-execution-generator)**: receipts in, Excel prep sheet out
- ⚽ **[World Cup '22 passing viz](https://bjrodriguez.shinyapps.io/world_cup22_passes/)**: every Argentina pass of the 2022 World Cup, clustered and clickable
- 📍 **[StudyBadger](https://github.com/bjrodrigu/Project_08)**: find and review study spots around UW–Madison on a live map
- 📊 **[sports-analytics](https://github.com/bjrodrigu/sports-analytics)**: Leverkusen set pieces, college football rivalry upsets, NFL receiver separation
- 🏃 **[fitness-tracker](https://github.com/bjrodrigu/fitness-tracker)**: my Garmin runs, pulled into an API I can search
